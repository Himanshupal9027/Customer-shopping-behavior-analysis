Customer Shopping Behavior Analysis

Project Overview

This project analyzes customer shopping behavior using transactional data from 3,900 purchases across multiple product categories. The objective is to uncover actionable insights related to customer spending patterns, purchasing preferences, subscription behavior, and customer segmentation to support data-driven business decisions. 

The project follows a complete analytics workflow:

- Data Cleaning & Preparation using Python
- Business Analysis using MySQL
- Data Visualization using Power BI
- Business Recommendations based on analytical findings

Project Workflow
1. Data Preparation and Cleaning (Python)

The dataset was processed using Python and Pandas.

Key tasks completed:

- Loaded data using Pandas
- Performed exploratory data analysis
- Identified missing values
- Imputed missing review ratings using category median values
- Standardized column names using snake_case
- Created age_group feature
- Created purchase frequency metrics
- Removed redundant columns after consistency validation
- Connected Python with MySQL
- Loaded cleaned data into the database for SQL analysis

---

SQL Business Analysis

Business-focused queries were developed in PostgreSQL to answer key stakeholder questions.

Analysis Performed

1. Revenue by Gender
Compared total revenue generated by male and female customers.

2. High-Spending Discount Users
Identified customers who used discounts while still spending above average. 

3. Top-Rated Products
Analyzed products with the highest average review ratings. 

4. Shipping Type Comparison
Compared average purchase amounts across shipping methods. 

5. Subscribers vs Non-Subscribers
Evaluated customer spending and revenue based on subscription status. 

6. Discount-Dependent Products
Identified products most reliant on discounts for purchases. 

7. Customer Segmentation
Classified customers into:

- New
- Returning
- Loyal
based on their purchase history. 

8. Top Products by Category
Determined the most purchased products within each category. 

9. Repeat Buyers & Subscription Analysis
Analyzed relationships between repeat purchases and subscription behavior. 

10. Revenue by Age Group
Measured revenue contribution across different age groups.
